# سجل الأدلة ونطاق الاستعمال

`parameter_registry.json` هو السجل الفعلي القابل للتحقق. يضم 68 قيمة عددية فعلية من config/افتراضات الغاز وأربع معلمات سيناريو. تُوسع القيم الافتراضية في Channel قبل فحص التغطية، حتى لا تختفي معلمات لم تُكتب صراحةً في JSON. لكل معلمة وحدة وقيمة اسمية ونقاط مسح ومصادر أو إعلان فرضية وحدود نقل وخطوة تحقق مطلوبة.

جميع نقاط المسح اختيارات بحثية صريحة؛ ليست توزيعًا سكانيًا ولا فاصل ثقة ولا مجال تشغيل آمن. `held_nominal` يعني عدم مسح المعلمة في هذه المرحلة، وليس أنها معلومة بلا عدم يقين. `qaif_calibrated=false` حتى عند توفر قيمة مرجعية عامة للفولاذ أو الشبكة المعيارية.

SCI P185 يعطي مرجعًا اسميًا عامًا لمعامل يونغ 210 GPa ونسبة بواسون 0.3 وتمدد 12×10⁻⁶/K؛ أبقينا يونغ السابق 200 GPa افتراضًا بحثيًا. جدول NIST المستضاف مرجع مقارنة عام لخواص الفولاذ؛ لا يحدد درجة فولاذ الأنبوب أو منحنى تغيره مع الحرارة. البيانات المرجعية محفوظة في `sources` مع الرابط والموضع وحدود النقل. PHMSA لا يبرر تحويل الحجم الاسمي إلى قطر داخلي أو نقل قياس جدار لعينتنا المعيارية.

`profiles.json` يفصل الأصل الهندسي المفترض عن بيئة الموقع. أصل فوق الأرض من GasLib، جدار/طلاء/ميزانية إجهاد مفترضة، ودرجة فولاذ ومواد لاصق وطلاء ودعامات مجهولة صراحةً. الموقعان إحداثيتا أرشيف NASA POWER، ولا يضيف قرب الساحل أو الصحراء احتمال أعطال تلقائيًا. لا يُمثل H₂S أو الصندوق/الراديو هنا.

الضجيج AR(1) واحتمال فقد الحزمة معرفان **لكل عينة محاكاة**. عند تغيير الشبكة من ساعة إلى 600 ثانية، لا تمثل القيم نفسها ثابتًا زمنيًا أو معدل اتصال ميدانيًا. الكسب والتأخر والبلل والضجيج كلها تحتاج قياسات جهاز/تثبيت ملائمة، وإن أمكن استخدامها لمسح حساسية معلن الآن.

تشغيل `python -m qaif_saddle_sim.build_evidence_study --out <مجلد جديد>` ينسخ السجل والملفات، ويخرج CSV للقراءة، ومسوحات أحادية العامل وأزواج ضابطة ومراجعة استقلال المصادر. لا تُدخل السجل أو المعرّفات أو مراحل التدخل إلى ميزات النموذج. تبقى المخرجات `training_ready=false`؛ مجموعة مصدر واحد لا تعطي أقسام تقييم مستقلة مهما كثر عدد النوافذ.
